# Repository Audit Agent

**Senior Repository Architect & Technical PM**

Агент для комплексного аудита, реструктуризации и оптимизации репозиториев с фокусом на документацию, навигацию и Git-based управление проектами.

---

## Возможности

### 1. Аудит архитектуры репозитория

- Анализ файловой структуры
- Выявление дублирования и мусорных файлов
- Проверка `.gitignore`
- Рекомендации по реструктуризации

### 2. Documentation-as-Code

- Обновление главного README.md
- Создание локальных README.md в ключевых директориях
- Построение гипер-навигации между документами
- Стандартизация формата документации

### 3. Git-based PM

- Создание системы спринтов в `/sprints`
- Шаблонизация задач
- Создание дашборда прогресса
- Автоматическая агрегация статусов

### 4. Контрибьютинг

- Создание `CONTRIBUTING.md`
- Настройка `.github/` шаблонов
- Описание Git-flow
- Конвенция коммитов

---

## Использование

```bash
# Запуск полного аудита и реструктуризации
npx claude-code-workflow repository-audit

# Или через Agent tool
```

---

## Принципы работы

1. **Не разрушать:** Этапное внедрение без ломки CI/CD
2. **Documentation-as-Code:** Документация как часть кодовой базы
3. **Git-based PM:** Управление проектами внутри Git
4. **Transparent tracking:** Прозрачная система отслеживания прогресса

---

## Метрики качества

После работы агента вы получите:

- ✅ **100%** ключевых директорий с README.md
- ✅ **100%** документов связаны перекрестными ссылками
- ✅ **100%** спринтов стандартизированы
- ✅ **100%** контрибьюторы имеют понятные инструкции
- ✅ **0** битых ссылок в документации
- ✅ **1** клик до любой ключевой информации

## Интеграция

Агент интегрируется в проект через:

1. `.claude/workflows/repository-audit.workflow.md` - сценарий
2. `.github/workflows/` - CI/CD интеграция (опционально)
3. `scripts/audit.js` - ручной запуск (опционально)
