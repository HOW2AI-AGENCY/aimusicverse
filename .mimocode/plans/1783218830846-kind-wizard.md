## Проблемы и риски

### 🔴 Критические

1. **Force-push в `main` продолжается** — Lovable коммиты с сообщением "Changes" пушатся напрямую в `main`, минуя pre-commit хуки. Это роняет CI и создаёт миграционный хаос. Branch protection Phase 1 настроена, но Phase 2 (required checks) заблокирована.

2. **Lovable коммиты без описания** — последние ~20 коммитов имеют сообщение "Changes" без содержательного описания. Это затрудняет ревью и git blame.

### 🟡 Средние

3. **Двойной lockfile** — `bun.lock` и `package-lock.json` существуют одновременно. Нужно решение владельца.

4. **16 файлов с prettier-дрейфом** — блокируют CI format check. Нужен format fix-up PR.

5. **E2E тесты не стабилизированы** — Sprint 035 перенёс E2E стабилизацию в Sprint 050, которая ещё не завершена.

### 🟢 Низкие

6. **Sprint 052-C cleanup** — Storybook stories для MashupDialog + i18n strings (отложено)

7. **12 функциональных флагов F1–F12** из Sprint 047 (useScrollLock, focus-trap, keyboard avoidance и др.) — переданы в Sprint 050 Phase B
