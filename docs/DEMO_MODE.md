# 🎭 Гостевой режим (Demo Mode)

## Обзор

MusicVerse AI теперь поддерживает **Гостевой режим** - возможность просматривать интерфейс и функционал приложения без авторизации через Telegram. Это позволяет пользователям оценить возможности платформы перед регистрацией.

## 🎯 Назначение

Гостевой режим предназначен для:

- **Демонстрации возможностей** - показать потенциальным пользователям интерфейс и функции
- **Тестирования** - проверить работу приложения без необходимости авторизации
- **Создания скриншотов** - получить визуальные материалы для документации
- **Разработки** - упростить локальную разработку и отладку UI

## 🚀 Как использовать

### Вход в гостевой режим

1. **Через страницу авторизации:**
   - Откройте приложение
   - На странице авторизации нажмите кнопку **"Попробовать без авторизации"** (с иконкой глаза 👁️)
   - Вы будете перенаправлены на главную страницу в гостевом режиме

2. **В режиме разработки:**
   - При открытии на localhost или lovable домене
   - Нажмите кнопку "Попробовать без авторизации"

### Индикатор гостевого режима

Когда вы находитесь в гостевом режиме, вверху экрана отображается синий баннер:

```
🎵 Гостевой режим • Просмотр без авторизации [Войти] [×]
```

- **Войти** - переход на страницу авторизации
- **×** - скрыть баннер (остаётесь в гостевом режиме)

## 📋 Доступные функции

### ✅ Что доступно в гостевом режиме

- **Просмотр интерфейса** - все страницы и компоненты видны
- **Навигация** - свободное перемещение по разделам
- **Публичный контент** - просмотр публичных треков, плейлистов, артистов
- **Воспроизведение** - прослушивание публичных треков
- **UI элементы** - взаимодействие с интерфейсом (меню, кнопки, фильтры)

### ❌ Что недоступно в гостевом режиме

- **Создание контента** - генерация музыки, создание плейлистов
- **Редактирование** - изменение треков, профиля
- **Лайки и сохранения** - взаимодействие с избранным
- **Комментарии** - добавление комментариев
- **Личная библиотека** - доступ к приватному контенту
- **Загрузка файлов** - скачивание треков, стемов

При попытке использовать недоступные функции появляется уведомление:

```
ℹ️ Войдите, чтобы использовать [функция]
   [Войти]
```

## 🛠️ Технические детали

### Архитектура

Гостевой режим реализован через:

1. **GuestModeContext** (`src/contexts/GuestModeContext.tsx`)
   - React Context для управления состоянием гостевого режима
   - Хранение preference в localStorage
   - Методы `enableGuestMode()` и `disableGuestMode()`

2. **GuestModeBanner** (`src/components/GuestModeBanner.tsx`)
   - Визуальный индикатор режима
   - Кнопки для входа и скрытия баннера

3. **useGuestAccess** (`src/hooks/useGuestAccess.tsx`)
   - Хук для проверки доступа к функциям
   - Методы `requireAuth()`, `isReadOnly()`, `canWrite()`

4. **ProtectedRoute** (обновлён)
   - Пропускает пользователей в гостевом режиме
   - Проверка: `if (!isAuthenticated && !isGuestMode)`

### Использование в компонентах

```typescript
import { useGuestAccess } from '@/hooks/useGuestAccess';

function MyComponent() {
  const { requireAuth, isReadOnly, canWrite } = useGuestAccess();

  const handleCreate = () => {
    // Проверяем авторизацию перед действием
    if (!requireAuth('создание трека')) return;

    // Действие доступно только авторизованным пользователям
    createTrack();
  };

  return (
    <div>
      {isReadOnly() && <p>Только просмотр</p>}
      <Button onClick={handleCreate} disabled={!canWrite()}>
        Создать
      </Button>
    </div>
  );
}
```

### LocalStorage

Гостевой режим сохраняет preference в localStorage:

```javascript
localStorage.setItem("guestMode", "true"); // Включён
localStorage.removeItem("guestMode"); // Выключен
```

## 🔐 Безопасность

- **Без доступа к данным** - гостевой режим не имеет доступа к приватным данным
- **Row Level Security** - БД защищена RLS политиками Supabase
- **Read-only API** - все мутации требуют авторизации
- **Публичный контент** - доступны только треки с `is_public = true`

## 🎨 Стиль и UX

### Баннер гостевого режима

- **Цвет:** Градиент от синего к фиолетовому (`from-blue-600 to-purple-600`)
- **Позиция:** Fixed вверху экрана (`top-0 z-50`)
- **Текст:** Белый, с эмодзи 🎵
- **Кнопки:** Ghost стиль с hover эффектом

### Кнопка "Попробовать без авторизации"

- **Иконка:** Eye (👁️) из lucide-react
- **Стиль:** Outline variant
- **Размер:** Large (`size="lg"`)
- **Текст:** "Попробовать без авторизации"

## 🧪 Тестирование

### Сценарии тестирования

1. **Вход в гостевой режим**
   - Открыть `/auth`
   - Нажать "Попробовать без авторизации"
   - Проверить наличие баннера

2. **Навигация**
   - Посетить все основные страницы
   - Проверить доступность публичного контента

3. **Попытка создания**
   - Попробовать создать трек
   - Должно появиться уведомление с предложением войти

4. **Переход к авторизации**
   - Нажать "Войти" в баннере
   - Проверить переход на `/auth`

## 📝 Примечания

- Гостевой режим автоматически активируется при клике на кнопку
- Режим сохраняется между сессиями через localStorage
- При входе через Telegram гостевой режим автоматически отключается
- Баннер можно скрыть, но режим остаётся активным
