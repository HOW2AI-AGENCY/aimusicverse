# User Flows Audit - MusicVerse AI

## Обзор

Документация текущих пользовательских путей для выявления проблем и упрощения интерфейса.

---

## 1. Flow генерации трека

### Текущее состояние (ПРОБЛЕМЫ)

```mermaid
graph TD
    A[Пользователь открывает приложение] --> B{Точки входа}

    B --> C1[FAB кнопка +]
    B --> C2[BottomNav: Создать]
    B --> C3[MusicLab страница]
    B --> C4[Library: Новый трек]
    B --> C5[Проект: Добавить трек]

    C1 --> D[GenerateSheet]
    C2 --> D
    C3 --> E[MusicLab с tabs]
    C4 --> D
    C5 --> F[Другой flow]

    D --> G{Режим генерации}
    G --> G1[Simple - описание]
    G --> G2[Custom - полный контроль]

    E --> H{MusicLab tabs}
    H --> H1[Генератор - то же что Simple]
    H --> H2[Лирика - отдельно]
    H --> H3[Стили - каталог]

    G1 --> I[Генерация...]
    G2 --> I
    H1 --> I

    I --> J{Результат}
    J --> K[❌ Переход в Library]
    J --> L[❌ Пользователь ищет трек]

    L --> M[Находит трек]
    M --> N[Прослушивает версии]
    N --> O{Выбор версии}

    style K fill:#f66
    style L fill:#f66
```

### Проблемы текущего flow:

1. **5 точек входа** — пользователь не знает где начать
2. **После генерации** — перенаправление в Library, потеря контекста
3. **Поиск трека** — пользователь должен сам найти только что созданный трек
4. **MusicLab дублирует** — та же функциональность, что и GenerateSheet

### Целевое состояние (УПРОЩЁННОЕ)

```mermaid
graph TD
    A[Пользователь] --> B{Хочет создать}

    B --> C[FAB или BottomNav: +Создать]

    C --> D[GenerateSheet]

    D --> E{Режим}
    E --> E1[Quick: описание на языке]
    E --> E2[Custom: стиль + лирика + теги]

    E1 --> F[Генерация...]
    E2 --> F

    F --> G[✅ GenerationResultSheet]

    G --> H[Показ обеих версий A/B]
    H --> I{Действия}

    I --> I1[🎧 Прослушать A]
    I --> I2[🎧 Прослушать B]
    I --> I3[⭐ Выбрать активную]
    I --> I4[🎛️ Открыть в студии]
    I --> I5[📁 В библиотеку]

    style G fill:#6f6
    style H fill:#6f6
```

## 2. Flow работы с версиями

### Текущее состояние

```mermaid
graph TD
    A[Трек в библиотеке] --> B{Где версии?}

    B --> C1[InlineVersionToggle в карточке]
    B --> C2[VersionSwitcher в плеере]
    B --> C3[VersionsSection в меню]
    B --> C4[CompactSheetHeader - badge]

    C1 --> D[Переключение версии]
    C2 --> D
    C3 --> D

    D --> E{Что происходит?}
    E --> F1[❓ Меняется audio_url трека]
    E --> F2[❓ Обновляется player]
    E --> F3[❓ Действия применяются к новой версии]

    style F1 fill:#ff9
    style F2 fill:#ff9
    style F3 fill:#ff9
```

### Проблемы:

1. **4 разных компонента** для одной функции
2. **Неясно что такое "активная версия"** — пользователь не понимает
3. **Нет подтверждения** что версия переключена
4. **Действия в меню** не показывают к какой версии применяются

### Целевое состояние

```mermaid
graph TD
    A[Трек] --> B[UnifiedVersionSelector]

    B --> C{Варианты отображения}
    C --> C1[Inline: A/B toggle с badge активной]
    C --> C2[Sheet: детальное сравнение]

    C1 --> D[Переключение]
    C2 --> D

    D --> E[Toast: Версия B теперь активная]
    E --> F[Все действия = к версии B]

    F --> G{Меню действий}
    G --> G1[Заголовок: Действия с версией B]
    G --> G2[Каждое действие понятно]

    style E fill:#6f6
    style G1 fill:#6f6
```

## 3. Flow перехода в студию

### Текущее состояние

```mermaid
graph TD
    A[Трек в библиотеке] --> B[Открыть меню]

    B --> C{Действия студии}
    C --> C1[Открыть в студии]
    C --> C2[Разделить на стемы - быстро]
    C --> C3[Разделить на стемы - детально]

    C1 --> D{Есть стемы?}
    D --> D1[Да → Студия]
    D --> D2[Нет → ???]

    C2 --> E[Разделение 2 дорожки]
    C3 --> F[Разделение 6+ дорожек]

    E --> G[Результат стемов]
    F --> G

    G --> H{Что дальше?}
    H --> H1[❓ Автоматом в студию?]
    H --> H2[❓ Остаёмся в библиотеке?]

    style D2 fill:#f66
    style H1 fill:#ff9
    style H2 fill:#ff9
```

### Проблемы:

1. **3 разных действия** для входа в студию
2. **Неясно нужны ли стемы** для студии
3. **После разделения стемов** — что дальше?
4. **"Открыть в студии"** — работает только если есть стемы?

### Целевое состояние (после Quick Win 2)

```mermaid
graph TD
    A[Трек] --> B[Меню: Стемы]

    B --> C[StemsActionButton]
    C --> D{Диалог выбора режима}

    D --> D1[Быстрый: 2 дорожки]
    D --> D2[Детальный: 6+ дорожек]

    D1 --> E[Разделение...]
    D2 --> E

    E --> F[Стемы готовы]
    F --> G[✅ Автоматический переход в студию]

    G --> H[StudioShell с дорожками]

    style G fill:#6f6
```

## 4. Flow навигации

### Текущее состояние

```mermaid
graph TD
    A[BottomNavigation] --> B{5 пунктов}

    B --> B1[🏠 Главная - Index]
    B --> B2[🎵 Треки - Library]
    B --> B3[➕ Создать - FAB]
    B --> B4[📁 Проекты - Projects]
    B --> B5[⋯ Ещё - MoreMenu]

    B5 --> C{Меню Ещё}
    C --> C1[Профиль]
    C --> C2[Настройки]
    C --> C3[MusicLab]
    C --> C4[Артисты]
    C --> C5[Плейлисты]
    C --> C6[Достижения]
    C --> C7[...]

    style C fill:#ff9
```

### Проблемы:

1. **Меню "Ещё"** — слишком много пунктов
2. **MusicLab** — дублирует функционал генерации
3. **Проекты** — редко используемая функция на главной навигации

## 5. Рекомендации по упрощению

### Приоритет 1: Post-Generation Flow

- [ ] Создать `GenerationResultSheet` — показ результата сразу после генерации
- [ ] Добавить прослушивание версий A/B
- [ ] Кнопка "Выбрать активную"
- [ ] Кнопка "В студию"

### Приоритет 2: Унификация версий

- [x] Badge активной версии в `CompactSheetHeader`
- [ ] Создать `UnifiedVersionSelector` компонент
- [ ] Заменить все 4 компонента на один

### Приоритет 3: Студия

- [x] Объединить stems_simple и stems_detailed (`StemsActionButton`)
- [ ] Автоматический переход в студию после разделения стемов
- [ ] Упростить StudioShell (разбить на подкомпоненты)

### Приоритет 4: Навигация

- [ ] Убрать MusicLab из навигации (функционал в GenerateSheet)
- [ ] Перенести "Проекты" в профиль или Library
- [ ] Упростить меню "Ещё"
