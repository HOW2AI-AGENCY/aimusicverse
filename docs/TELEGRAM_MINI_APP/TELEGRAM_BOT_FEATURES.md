# Telegram Bot - Глубокая Интеграция

## 🚀 Обзор

Telegram бот MusicVerse обеспечивает полноценную интеграцию с приложением, позволяя пользователям управлять музыкой прямо из Telegram.

## 📋 Основные Функции

### 1. 🎼 Генерация Треков

- Команда: `/generate <описание>`
- Параметры:
  - `--instrumental` - Создать инструментальный трек
  - `--model=V5` - Выбрать модель генерации
  - `--mode=custom` - Пользовательский режим

**Примеры:**

```
/generate энергичный рок трек
/generate --instrumental ambient space music
/generate --model=V5 классическая симфония
```

### 2. 📚 Библиотека

- Команда: `/library`
- Показывает последние 5 треков
- Каждый трек имеет команду `/track_<id>` для детального просмотра
- Inline кнопки для быстрого доступа

### 3. 📁 Проекты

- Команда: `/projects`
- Список всех музыкальных проектов
- Быстрый переход к проекту через inline кнопки

### 4. ⚡ Статус Генерации

- Команда: `/status`
- Показывает активные задачи генерации
- Кнопка "Проверить статус" для обновления
- Real-time отслеживание через API Suno

### 5. 📤 Отправка Треков

#### 5.1 Отправка в Чат

- Автоматическая отправка готовых треков в Telegram
- Полная информация: название, стиль, длительность
- Обложка трека как thumbnail
- Inline кнопки для действий

#### 5.2 Делиться с Друзьями

- Кнопка "Поделиться с друзьями" использует `switch_inline_query`
- Отправка трека в любой чат через inline режим
- Формат: `@bot_name track_<id>`

#### 5.3 Поделиться в Историю

- Кнопка "Поделиться в историю"
- Использует Telegram Stories API
- Автоматическое форматирование для stories

#### 5.4 Копировать Ссылку

- Генерация deep link на трек
- Формат: `https://t.me/bot_name/app?startapp=track_<id>`
- Простое копирование и отправка

### 6. 🔔 Уведомления

#### 6.1 Типы Уведомлений

- ✅ **Готовые треки** - Когда генерация завершена
- ❌ **Ошибки** - При сбое генерации
- ⏳ **Статус** - Обновления прогресса

#### 6.2 Настройки Уведомлений

- Команда: `/settings` → Уведомления
- Варианты:
  - 🔔 Все уведомления
  - ✅ Только готовые треки
  - ❌ Только ошибки
  - 🔕 Отключить все

### 7. 🎨 Эмодзи Статус

Установка эмодзи статуса в профиле Telegram:

- 🎵 Слушаю музыку
- 🎼 Создаю треки
- 🎧 В наушниках
- 🎸 Рок-звезда
- 🎹 Композитор

**Использование:**

1. `/settings` → Эмодзи статус
2. Выбрать нужный статус
3. Статус отображается 12 часов

## 🔧 Технические Детали

### Deep Links

Бот поддерживает следующие deep links:

1. **Трек:** `https://t.me/bot_name/app?startapp=track_<id>`
2. **Проект:** `https://t.me/bot_name/app?startapp=project_<id>`
3. **Генерация:** `https://t.me/bot_name/app?startapp=generate_<style>`

### Inline Mode

Формат: `@bot_name <команда>`

Примеры:

- `@bot_name track_<id>` - Поделиться треком
- `@bot_name search <запрос>` - Найти треки

### Автозамена/Автоудаление

Все сообщения бота с inline кнопками автоматически:

- **Заменяются** при переходе по кнопкам навигации
- **Сохраняются** для истории треков и проектов
- **Удаляются** при завершении действия

Используется метод `editMessageText` вместо отправки новых сообщений.

## 📊 Статистика и Аналитика

Бот отслеживает:

- Количество генераций
- Успешные/неудачные попытки
- Время генерации
- Популярные стили
- Активность пользователей

## 🔐 Безопасность

- Все команды требуют аутентификации через Mini App
- Проверка пользователя через `profiles` таблицу
- Rate limiting на генерацию
- Валидация всех входных данных

## 📱 Команды

### Основные

- `/start` - Начало работы с ботом
- `/help` - Справка по командам
- `/generate <описание>` - Создать трек
- `/library` - Мои треки
- `/projects` - Мои проекты
- `/status` - Статус генерации
- `/settings` - Настройки
- `/app` - Открыть приложение

### Специальные

- `/track_<id>` - Детали трека
- `/project_<id>` - Детали проекта

## 🎯 Сценарии Использования

### Сценарий 1: Быстрая Генерация

1. `/start` → Кнопка "Создать трек"
2. Выбор стиля или своё описание
3. Отправка описания
4. Получение уведомления
5. Прослушивание/скачивание

### Сценарий 2: Делиться Треком

1. `/library` → Выбор трека
2. Кнопка "Поделиться"
3. Выбор способа (чат/история/ссылка)
4. Подтверждение

### Сценарий 3: Отслеживание Статуса

1. `/status` → Просмотр активных задач
2. Кнопка "Проверить статус"
3. Автообновление информации
4. Уведомление о готовности

## 🚦 Состояния Трека

- ⏳ **PENDING** - В очереди
- 🔄 **PROCESSING** - Генерируется
- ✅ **COMPLETED** - Готов
- ❌ **FAILED** - Ошибка

## 💡 Советы

1. **Детальные описания** - Чем подробнее описание, тем лучше результат
2. **Параметры** - Используйте `--instrumental` для инструменталов
3. **Модели** - V5 для лучшего качества, V4 для скорости
4. **Статусы** - Установите эмодзи статус для атмосферы
5. **Уведомления** - Настройте под свои нужды

## 🔄 Обновления

Бот автоматически обновляется при изменении кода edge functions.
Все новые функции добавляются без необходимости перезапуска.
