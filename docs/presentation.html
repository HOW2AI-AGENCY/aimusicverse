Минуты, а не смены

Одно сообщение — и через пару минут у вас два варианта готовой песни с вокалом. Версии A и B: оставьте прочтение, которое зацепило, вторую сохраните про запас.

Генераторы обычно заканчиваются кнопкой «Скачать». Здесь с неё всё начинается: стемы, микшер, замена неудачного куплета, MIDI-партитуры и собственный голос.

AI-харнесс9 инструментов · Gemini 2.5 Flash · SSE streaming

Девять инструментов, один эндпоинт

AI-помощник лирики — это не «промпт в LLM». Это трёхслойный харнесс: action-пресеты UI, контекстный билдер и Edge Function с реестром промптов. Модель получает не просто текст, а полный контекст альбома.

fig. — Три слоя: action-пресеты (слева) → контекст (центр) → Edge Function + LLM (справа)

Контекст альбома

Модель знает, что пишет трек №3 из 12 в концептуальном альбоме — жанр, настроение, позицию, заметки AI-планировщика и тексты соседних треков. Не изолированный текст, а часть истории.

Action-пресеты вместо function-calling

Девять инструментов: написать, продолжить, проанализировать, продюсерский разбор, Suno-оптимизация, рифмы, структура, стиль, перевод. Каждый возвращает предсказуемый JSON — без сюрпризов.

Streaming

Текст появляется токен за токеном через Server-Sent Events. Пользователь видит первую строку через ~800ms после нажатия, а не ждёт 10 секунд полного ответа.

Промпт-реестр

Базовый промпт — 200 строк с полной библиотекой Suno V5 тегов, правилами слогового счёта, схемами рифмовки и антипаттернами. Action-промпты добавляют специализацию: JSON-контракты для анализа, вокальные карты для продюсера, Drill-структуры для хип-хопа.

Блокировки в РФ

Supabase и LLM недоступны напрямую

Значительная часть пользователей — из России, где OpenAI, Anthropic и часть CDN заблокированы. Прямой вызов api.openai.com из Telegram WebView в iOS не проходит.

Решение

Lovable AI Gateway как единая точка входа: запрос идёт через ai.gateway.lovable.dev, который маршрутизируется и ретраится. Edge Function в Supabase Cloud доступна из РФ через собственную CDN.

Результат: пользователи из Москвы и Пхукета получают одинаковую скорость генерации.

Скорость в Mini App

WebView ≠ браузер

Telegram Mini App работает в WebView (Chrome на Android, WKWebView на iOS). Разница в производительности — 3-4x. Бандл 2 МБ gzipped давал 4-6 секунд первого рендера на 3G.

Решение

Code-splitting по маршрутам, lazy-loading Recharts (14 компонентов), SSE streaming вместо ожидания полного ответа, централизованные иконки для tree-shaking.

Результат: 2 МБ → 480 КБ бандл, первый рендер ~1.2с на 3G.

Хрупкость JSON

LLM возвращает грязный JSON

Gemini 2.5 Flash в 5% случаев оборачивает JSON в markdown, добавляет trailing commas или не закрывает скобки. Frontend падает на парсинге.

Решение

Двухуровневый парсер: backend извлекает JSON greedy-регулярками, фронтенд нормализует через extractJSON() с fallback на raw text. Стриминг аккумулирует сырой текст и извлекает поле "lyrics" на лету.

Результат: 95% успешных парсингов, fallback на raw-текст для остальных 5%.

Инженерные вызовыпроблема · решение · результат

Сложные задачи, которые пришлось решить

За гладким интерфейсом — несколько нетривиальных инженерных проблем. Вот главные из них и то, как они закрыты.

Аудио на iOS

Safari падает от множества плееров

Safari на iPhone аварийно закрывает вкладку, когда на странице больше десятка аудиоэлементов. Музыкальному приложению их нужно много: превью версий, стемы, запись голоса.

Решение

Весь звук идёт через один аудиоэлемент на всё приложение, плюс пул переиспользуемых элементов для превью.

Результат: плеер не падает и не заикается даже на старых iPhone.

Скорость запуска

Мгновенное открытие против объёма кода

Мини-приложение должно открываться сразу, но полный интерфейс — это больше мегабайта кода при первом входе.

Решение

Разбиение на модули, ленивая загрузка экранов и точечная сборка с жёстким бюджетом на размер.

Результат: холодный старт 508 КБ, вдвое с лишним легче.

Версии A/B

Показано одно, играет другое

У каждого трека два варианта. При переключении легко получить рассинхрон: на экране версия A, а из динамика звучит B.

Решение

Активная версия переключается атомарно: все связанные данные меняются одной операцией, с журналом изменений.

Результат: то, что вы видите, всегда совпадает с тем, что слышите.

Эргономика телефона

Клавиатура и вырезы перекрывают экран

Клавиатура Telegram и вырезы дисплея закрывают интерфейс, а попадать пальцем по мелким кнопкам неудобно.

Решение

Интерфейс подстраивается под видимую область: безопасные отступы, цели касания ≥ 44 px, шторки вместо диалогов и тактильный отклик.

Результат: студия удобно управляется одним большим пальцем.

Надёжность при росте

Быстрый темп грозит регрессиями

Функциональность растёт быстро, и без страховки любое изменение рискует незаметно сломать соседний модуль.

Решение

1810 автотестов и 58 E2E-сценариев в шести браузерах, строгая типизация без «any», проверки на каждый коммит.

Результат: релизы без сюрпризов, ноль ошибок типизации.

Безопасность данных

Чувствительные данные и платежи

Генерации, треки и оплаты — данные, которые нельзя терять или раскрывать, а секреты недопустимо держать на стороне клиента.

Решение

Доступ ограничен политиками на уровне базы данных, секреты живут только в серверных функциях, внешние колбэки подписаны, зависимости регулярно проверяются.

Результат: аудит июля 2026, критические замечания закрыты.
