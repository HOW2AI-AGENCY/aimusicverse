## P0 Issues — Critical Blockers (RESOLVED ✅)

### P0-1: Telegram Deep-link Non-functional ✅

**Issue:** startapp=generate redirects to / without opening GenerateSheet. Telegram bot feature dead.

**Solution (055-A5):**

- DeepLinkHandler navigates + triggers sheet open
- Parameter stripped after execution

**Status:** ✅ RESOLVED

---

### P0-2: Dual CTA Confusion ✅

**Issue:** Telegram MainButton hidden, UI button fallback-only.

**Solution (055-B1):** Always show BOTH buttons.

**Status:** ✅ RESOLVED

---

### P0-3: Save Draft No-Op ✅

**Issue:** Save button only shows toast, no real save.

**Solution (055-A1, A2, A3):** Wire useGenerateDraft.save() + unit test.

**Status:** ✅ RESOLVED

---

### P0-4: Generation Cancel Hardcoded False ✅

**Issue:** showCancel={false} → can't abort generation.

**Solution (055-A4):** Soft-cancel via useSunoCancel.

**Status:** ✅ RESOLVED (PR #618)

---

### P0-5: Welcome Bonus Repeatable ✅

**Issue:** No idempotency guard.

**Solution (055-A6):** TTL-based 30-day guard.

**Status:** ✅ RESOLVED
