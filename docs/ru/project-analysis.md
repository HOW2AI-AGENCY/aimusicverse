### ⚠️ Критические улучшения (P0)

```
1. AudioContext management
   Проблема: Memory leaks
   Решение: State machine + cleanup (2-3 дня)

2. Mobile audio limits
   Проблема: Safari ограничивает 6-8 элементов
   Решение: Audio pooling (2-3 дня)

3. Waveform блокирует UI
   Проблема: Main thread freeze (200-500ms)
   Решение: Web Worker (2-3 дня)
```

### 🚀 Приоритетные улучшения (P1)

```
1. Lyrics Wizard
   ├─ LocalStorage persistence
   ├─ Undo/Redo (20 states)
   ├─ Правильный подсчет символов
   └─ Валидация с debouncing

2. Component optimization
   ├─ React.memo (StemChannel, TrackCard)
   └─ Custom comparison functions

3. Mobile consolidation
   ├─ 29 → 18 компонентов (-38%)
   ├─ ~5,925 → ~4,225 LOC (-29%)
   └─ Universal MobileTabBar

4. Keyboard shortcuts
   ├─ Global (Space, Arrows, M, F, L)
   └─ Studio (S-solo, M-mute, 1-9-select)
```
