## 2. Новые находки этого прохода

1. **Три реализации haptic feedback** (а не две, как значилось в бэклоге):
   - `src/lib/haptic.ts` — канонические утилиты с version-guard (Telegram < 6.1);
   - `src/hooks/useHapticFeedback.ts` — канонический хук (47 импортёров), version-guard + fallback на Vibration API;
   - `src/lib/mobile-utils.ts` — дубликат `useHapticFeedback(type)` с другой сигнатурой, **без version-guard** и с `any`-кастами. 2 импортёра.
2. **Мёртвый код:** `src/hooks/useOffline.ts` — 0 импортёров, дублировал `useOnlineStatus`/`useOfflineStatus`.
3. **Форма генерации (`GenerateFormSimple`)** — главный экран воронки:
   - кнопки «Стили» (Palette) и «AI Boost» в шапке секции — 36 px (`h-9`), ниже минимума 44 px, при том что остальные кнопки той же формы уже `h-11`;
   - `navigator.clipboard.writeText` без обработки ошибки — необработанный promise rejection вне secure context / при запрете в webview;
   - px-типографика (`text-[15px]`, `text-[13px]`, `text-[11px]`) вместо type-токенов; 15 px на `<textarea>`/`<input>` дополнительно провоцирует автозум iOS Safari (зумит поля < 16 px).
4. **Sidebar (collapsed):** индикатор активных генераций — `h-10` (40 px) без `min-h-[44px]`, единственная оставшаяся кнопка ниже минимума в этом компоненте.
5. **4 offline-хука** с пересекающейся ответственностью: `useOnlineStatus` (баннер), `useOfflineStatus` (студия), `useNetworkStatus` (качество соединения для аудио — легитимно отдельный), `useOffline` (мёртвый).

## 4. Рекомендации (следующие итерации, по приоритету)

1. **Объединить `useOnlineStatus` и `useOfflineStatus`** — один хук сетевого статуса для баннера и студии (`useNetworkStatus` оставить: другая ответственность — качество соединения). ~2–3 ч.
2. **Скелетоны Library** — 3 системы для одного контента (`ui/skeleton-components`, `mobile/MobileSkeletons`, `library/GeneratingTrackSkeleton`). `GeneratingTrackSkeleton` легитимен (прогресс генерации), но mobile/desktop скелетоны карточек трека стоит свести к одному компоненту с вариантами, чтобы загрузка выглядела одинаково на брейкпоинтах. ~0.5 дня.
3. **Typography-долг вне горячих путей** — px-размеры остаются в `mobile-utils`-потребителях и admin-страницах (lint уже подсвечивает warning'ами; кодмод по точным соответствиям токенов: 11px→caption-sm, 12px→caption, 13px→body-sm/md, 14px→body, 16px→body-lg).
4. **`min-h-screen` → `min-h-dvh`** остатки в `MainLayout`/`Index` — на мобильном Telegram виден скачок высоты при скрытии тулбара.
5. **Визуальная унификация h-9/h-10 при min-h-[44px]** в `CompactFilterBar` — сейчас deliberate compact-режим на desktop (`min-h-[44px] md:min-h-[36px]`), трогать не стал: паттерн осознанный, зафиксировать его в дизайн-гайде.
