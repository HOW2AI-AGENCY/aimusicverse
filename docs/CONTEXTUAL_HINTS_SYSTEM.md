# Система контекстных подсказок

## Обзор

Система контекстных подсказок предоставляет периодические всплывающие подсказки для пользователей о возможностях платформы MusicVerse AI. Подсказки показываются автоматически в зависимости от контекста и поведения пользователя.

## Архитектура

### Компоненты

1. **useContextualHints** (`src/hooks/useContextualHints.ts`)
   - Хук для управления состоянием подсказок
   - Отслеживание количества посещений
   - Проверка условий показа
   - Сохранение состояния в localStorage

2. **ContextualHint** (`src/components/hints/ContextualHint.tsx`)
   - Визуальный компонент всплывающей подсказки
   - Анимация появления/исчезновения
   - Кнопки действий и закрытия

3. **HintsSettings** (`src/components/settings/HintsSettings.tsx`)
   - Панель управления подсказками в Settings
   - Просмотр всех подсказок
   - Статистика и управление

4. **MainLayout** (`src/components/MainLayout.tsx`)
   - Интеграция подсказок в основной layout
   - Глобальный показ подсказок

## Логика показа

### Условия

Каждая подсказка имеет следующие параметры:

- **showOnRoutes** - На каких страницах показывать (например: `['/', '/library']`)
- **minVisits** - Минимальное количество посещений до показа
- **cooldownHours** - Минимальный интервал между показами (часы)
- **maxShows** - Максимальное количество показов
- **priority** - Приоритет (выше = показывается раньше)

### Алгоритм

1. Загрузка состояния из localStorage
2. Инкремент счётчика посещений
3. Фильтрация подсказок по условиям:
   - Не отклонена навсегда
   - Не превышен maxShows
   - Достигнут minVisits
   - Прошёл cooldown с последнего показа
   - Текущая страница в showOnRoutes
4. Сортировка по приоритету
5. Автоматический показ через 5 секунд после загрузки страницы

## Использование

### В компонентах

```typescript
import { useContextualHints } from '@/hooks/useContextualHints';
import { ContextualHint } from '@/components/hints/ContextualHint';

function MyComponent() {
  const location = useLocation();
  const { currentHint, dismissHint } = useContextualHints(location.pathname);

  return (
    <>
      {/* Ваш контент */}

      {currentHint && (
        <ContextualHint
          hint={currentHint}
          onDismiss={dismissHint}
          position="bottom"
        />
      )}
    </>
  );
}
```

### Управление подсказками

Пользователи могут управлять подсказками в **Settings → Подсказки**:

- Просмотреть статистику (количество посещений, доступных подсказок)
- Посмотреть следующую подсказку
- Сбросить все подсказки (для повторного просмотра)
- Увидеть список всех подсказок с индикацией доступности

## Хранение данных

### localStorage Keys

- **musicverse-contextual-hints** - Состояние всех подсказок

  ```typescript
  {
    [hintId: string]: {
      lastShown: number;    // timestamp последнего показа
      showCount: number;    // сколько раз показано
      dismissed: boolean;   // отклонена навсегда
    }
  }
  ```

- **musicverse-visit-count** - Общее количество посещений

## Добавление новых подсказок

Чтобы добавить новую подсказку, отредактируйте массив `CONTEXTUAL_HINTS` в `src/hooks/useContextualHints.ts`:

```typescript
{
  id: 'unique-hint-id',
  category: 'ai-feature',
  title: '🎵 Новая функция!',
  description: 'Описание новой функции...',
  action: {
    label: 'Попробовать',
    route: '/path/to/feature',
  },
  showOnRoutes: ['/', '/library'],
  minVisits: 2,
  cooldownHours: 72,
  maxShows: 3,
  priority: 8,
}
```

## Рекомендации

### Для контента подсказок

- ✅ Используйте эмодзи в заголовках для визуальной привлекательности
- ✅ Описание должно быть кратким (1-2 предложения)
- ✅ Указывайте конкретную выгоду для пользователя
- ✅ Добавляйте action для перехода к функции

### Для параметров показа

- **minVisits**: 1-3 для важных функций, 5+ для продвинутых
- **cooldownHours**: 48-72 для частых, 120-168 для редких
- **maxShows**: 2-3 для обучающих, 1 для информационных
- **priority**: 8-10 для новых функций, 5-7 для советов

## Тестирование

### Локальное тестирование

1. Откройте Settings → Подсказки
2. Нажмите "Сбросить все" для очистки состояния
3. Обновите страницу
4. Подсказки начнут показываться автоматически

### Тестирование в коде

```typescript
const { resetAllHints, getNextHint, canShowHint } = useContextualHints("/");

// Сброс всех подсказок
resetAllHints();

// Проверка следующей подсказки
const next = getNextHint();
console.log("Next hint:", next);

// Проверка конкретной подсказки
const hint = CONTEXTUAL_HINTS[0];
console.log("Can show:", canShowHint(hint));
```

## Метрики

Система автоматически отслеживает:

- Количество посещений пользователя
- Количество показов каждой подсказки
- Время последнего показа
- Отклонённые подсказки

Эти данные можно использовать для:

- Персонализации опыта
- Анализа эффективности подсказок
- A/B тестирования различных сообщений
