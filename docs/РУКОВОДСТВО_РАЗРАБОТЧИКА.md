### 📁 Ключевые директории

#### `src/api/` - API Layer

Прямые запросы к Supabase с типизацией:

```typescript
// src/api/tracks.api.ts
export const getTrackById = async (id: string) => {
  const { data, error } = await supabase
    .from("tracks")
    .select("*, track_versions(*)")
    .eq("id", id)
    .single();
  
  return { data, error };
};
```

#### `src/services/` - Service Layer

Бизнес-логика и трансформация данных:

```typescript
// src/services/tracks.service.ts
export const enrichTrackWithMetadata = async (track: Track) => {
  const versions = await getTrackVersions(track.id);
  const metadata = await calculateMetadata(track);
  
  return {
    ...track,
    versions,
    metadata,
  };
};
```

#### `src/hooks/` - Hook Layer

React Query интеграция и state management:

```typescript
// src/hooks/useTracks.ts
export const useTrack = (id: string) => {
  return useQuery({
    queryKey: ["track", id],
    queryFn: () => getTrackById(id),
    staleTime: 30 * 1000, // 30 seconds
    gcTime: 10 * 60 * 1000, // 10 minutes
  });
};
```

## 📊 Best Practices

### 🎯 Component Patterns

#### 1. Используйте LazyImage для изображений

```typescript
// ❌ Плохо
<img src={url} alt="track" />

// ✅ Хорошо
import { LazyImage } from '@/components/ui/lazy-image';
<LazyImage src={url} alt="track" />
```

#### 2. Используйте cn() для className

```typescript
// ❌ Плохо
className={`base-class ${condition && 'extra-class'} ${className}`}

// ✅ Хорошо
import { cn } from '@/lib/utils';
className={cn('base-class', condition && 'extra-class', className)}
```

#### 3. Lazy loading для тяжелых компонентов

```typescript
// ❌ Плохо
import { HeavyComponent } from './HeavyComponent';

// ✅ Хорошо
const HeavyComponent = lazy(() => import('./HeavyComponent'));
```

### 🎯 State Management

#### 1. Правильный выбор state management

```typescript
// ✅ Zustand для глобального UI state
const playerStore = usePlayerStore();

// ✅ TanStack Query для server state
const { data } = useTrack(trackId);

// ✅ React Hook Form для форм
const { register, handleSubmit } = useForm();

// ✅ useState для локального state
const [isOpen, setIsOpen] = useState(false);
```

#### 2. Optimistic updates

```typescript
// ✅ Оптимистичные обновления
const queryClient = useQueryClient();

const likeMutation = useMutation({
  mutationFn: likeTrack,
  onMutate: async (trackId) => {
    // Optimistic update
    queryClient.setQueryData(['track', trackId], (old) => ({
      ...old,
      isLiked: true,
      likesCount: old.likesCount + 1,
    }));
  },
  onSettled: () => {
    // Refetch
    queryClient.invalidateQueries(['track', trackId]);
  },
});
```

  style={{ height: 400 }}
