## 🚀 Начало работы

### Первые шаги

1. **Найдите бота:** Откройте Telegram и найдите `@AIMusicVerseBot`
2. **Запустите бота:** Нажмите кнопку "START" или отправьте `/start`
3. **Откройте студию:** Нажмите кнопку "🚀 Открыть студию" для полного доступа
4. **Создайте первый трек:** Используйте команду `/generate` или выберите "🎼 Генератор"

### Основные команды

| Команда                | Описание                 |
| ---------------------- | ------------------------ |
| `/start`               | Показать главное меню    |
| `/help`                | Справка по всем командам |
| `/generate <описание>` | Создать трек             |
| `/library`             | Показать последние треки |
| `/status`              | Статус генерации         |
| `/settings`            | Настройки бота           |

## 🎼 Генерация музыки

### Способ 1: Быстрая генерация

Просто опишите желаемую музыку:

```
/generate энергичный рок трек с гитарными риффами
```

**Примеры:**

- `/generate спокойная джазовая композиция для вечера`
- `/generate энергичная электроника для тренировки`
- `/generate романтическая баллада о любви`

### Способ 2: Пошаговый мастер (NEW!)

Используйте интерактивный мастер для детальной настройки:

1. Отправьте `/generate` без описания
2. Выберите "🎨 Создать свой"
3. Пройдите пошаговую настройку:
   - **Шаг 1:** Выберите стиль (Рок, Поп, Джаз, и т.д.)
   - **Шаг 2:** Тип трека (С вокалом / Инструментал)
   - **Шаг 3:** Настроение (Энергичный, Спокойный, и т.д.)
   - **Шаг 4:** Темп (Медленный, Средний, Быстрый)
   - **Шаг 5:** Модель AI (V5 / V4)
   - **Шаг 6:** Дополнительное описание
   - **Шаг 7:** Предпросмотр и подтверждение

### Способ 3: Готовые шаблоны (NEW!)

Выберите один из готовых шаблонов:

- 🎹 **Расслабляющее фортепиано** - Спокойная инструментальная композиция
- ⚡ **Энергия для тренировки** - Мощный электронный бит
- 💕 **Романтическая баллада** - Лирическая композиция о любви
- 🎸 **Рок-гимн** - Энергичный рок с мощными риффами
- 🌙 **Ночная атмосфера** - Мечтательный эмбиент
- ☕ **Утренний джаз** - Приятный джаз для начала дня

**Как использовать:**

```
/generate
→ Выберите "🎯 Быстрая генерация"
→ Выберите шаблон
→ Подтвердите или измените параметры
```

### Расширенные параметры

Используйте флаги для точной настройки:

```
/generate --instrumental --model=V5 энергичная композиция
```

**Доступные флаги:**

- `--instrumental` - Без вокала
- `--style="стиль"` - Музыкальный стиль
- `--model=V5` - Использовать модель V5 (новая, лучшее качество)
- `--model=V4` - Использовать модель V4 (стабильная)

**Примеры:**

```
/generate --instrumental --style="epic orchestral" --model=V5
/generate --style="lo-fi hip hop" спокойная музыка для учёбы
```

### Что вы получите

После генерации вы получите:

- 🎵 **2 версии трека** (A и B) для сравнения
- ⏱️ **Длительность:** около 2-3 минут каждая
- 📥 **Форматы:** MP3 и WAV (через приложение)
- 🎨 **Обложка:** автоматически сгенерированная
- 📝 **Метаданные:** название, стиль, теги

## 📤 Загрузка аудио

### Создание кавера

Создайте новую версию вашей мелодии:

**Шаг 1:** Запустите команду

```
/cover
```

**Шаг 2:** Настройте параметры (NEW!)

- Выберите стиль кавера
- Укажите тип (с вокалом / инструментал)
- Выберите модель AI

**Шаг 3:** Отправьте аудиофайл

- Форматы: MP3, WAV, OGG, M4A
- Максимальный размер: 25 MB
- Рекомендуемая длительность: 30-180 секунд

**Шаг 4:** Подтвердите

- Просмотрите параметры
- Прослушайте оригинал
- Запустите обработку

**С параметрами:**

```
/cover --style="indie rock" --instrumental
→ Отправьте аудиофайл
```

### Расширение трека

Продолжите вашу композицию:

**Шаг 1:** Запустите команду

```
/extend
```

**Шаг 2:** Настройте параметры (NEW!)

- Выберите длину продолжения (30/60/90 сек)
- Укажите стиль (продолжить / изменить)
- Добавьте описание

**Шаг 3:** Отправьте исходный трек

**Шаг 4:** Дождитесь результата

**С параметрами:**

```
/extend --title="My Song Part 2" продолжение эпической композиции
→ Отправьте аудиофайл
```

### Поддерживаемые форматы

| Формат | Макс. размер | Примечания      |
| ------ | ------------ | --------------- |
| MP3    | 25 MB        | Рекомендуется   |
| WAV    | 25 MB        | Лучшее качество |
| OGG    | 25 MB        | Поддерживается  |
| M4A    | 25 MB        | iOS формат      |

## ❓ Часто задаваемые вопросы

### Генерация

**Q: Сколько времени занимает генерация?**  
A: Обычно 1-3 минуты. Вы получите уведомление когда трек будет готов.

**Q: Почему я получаю 2 версии трека?**  
A: AI создаёт 2 варианта (A и B), чтобы вы могли выбрать лучший.

**Q: Можно ли изменить длительность трека?**  
A: Стандартная длительность 2-3 минуты. Используйте `/extend` для продолжения.

**Q: Какую модель выбрать - V5 или V4?**  
A: V5 - новая модель с лучшим качеством. V4 - стабильная и быстрая.

### Загрузка аудио

**Q: Какой формат лучше загружать?**  
A: WAV для лучшего качества, MP3 для удобства.

**Q: Есть ли ограничение на размер файла?**  
A: Да, максимум 25 MB (ограничение Telegram).

**Q: Можно ли загружать аудио с вокалом?**  
A: Да, можно загружать любое аудио. Для кавера AI сохранит или изменит вокал по вашему выбору.

### Кредиты и оплата

**Q: Как получить бесплатные кредиты?**  
A: При регистрации вы получаете 50 бесплатных кредитов для первых треков.

**Q: Что такое Telegram Stars?**  
A: Внутренняя валюта Telegram для оплаты сервисов. Можно купить в настройках Telegram.

**Q: Возвращаются ли кредиты при ошибке?**  
A: Да, если генерация не удалась по нашей вине, кредиты возвращаются автоматически.

### Проблемы

**Q: Бот не отвечает**  
A:

1. Проверьте соединение с интернетом
2. Попробуйте команду `/start`
3. Напишите в поддержку: @AIMusicVerseSupport

**Q: Генерация зависла**  
A:

1. Проверьте статус: `/status`
2. Подождите 5 минут
3. Если не помогло - отмените и попробуйте снова

**Q: Плохое качество трека**  
A:

1. Используйте более детальное описание
2. Попробуйте модель V5
3. Сгенерируйте ещё раз - AI создаст другие варианты

## 🎯 Советы и хитрости

### Для лучших результатов

3. **Указывайте инструменты** - "с электрогитарой", "фортепиано и саксофон"
4. **Экспериментируйте** - Пробуйте разные стили и настроения
5. **Сохраняйте лучшее** - Добавляйте треки в плейлисты
