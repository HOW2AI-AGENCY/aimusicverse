# Plan: Full UI Redesign — Glassmorphism + Animated Gradients + Neon Glow + Progressive Blur

## Context

Current UI is functional but visually flat — dark navy background (#1a1a2e), basic glass utilities, disjointed animation files. Goal: premium, immersive music app feel with modern CSS effects while keeping ~950KB bundle limit. Effects are pure CSS — zero JS cost.

## Scope

**CSS Foundation** (1 new file + edits to 2 files) → **Layout Shell** (2 components) → **Key Pages** (4-5 pages)

---

### 1. CSS Effects Foundation — `src/styles/effects.css` (NEW)

Single file containing all new visual effects:

| Effect                 | Implementation                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Glass variants**     | `.glass-sm` / `.glass-md` / `.glass-lg` / `.glass-heavy` — progressive `backdrop-filter: blur(4px/8px/16px/24px) saturate(180%)` + HSL bg/border per level |
| **Progressive blur**   | `.blur-progressive` — scroll-aware via CSS `animation-timeline: scroll()` (Chrome 115+) with `@keyframes blur-in`                                          |
| **Animated gradients** | `@property --gradient-angle` + `.animated-gradient` — rotates hue over time. `.gradient-shift` — slides gradient position                                  |
| **Neon glow**          | `.neon-glow` / `.neon-glow-text` — `text-shadow` with `@keyframes neon-pulse` using CSS `filter: brightness()` animation                                   |
| **Aurora background**  | `.aurora-bg` — multiple blurry color blobs with `@keyframes aurora-drift` (translate + scale), GPU-composited                                              |
| **Breathing glow**     | `.glow-breathe` — `box-shadow` pulsing via `@keyframes breathe`                                                                                            |
| **Frosted depth**      | `.frost-1`/`.frost-2`/`.frost-3` — layered backdrop with increasing blur for modal stacks                                                                  |

Progressive enhancement: all effects degrade gracefully on `@media (prefers-reduced-motion: reduce)`.
