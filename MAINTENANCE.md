# 🛠 Руководство по поддержке репозитория

**MusicVerse AI — поддержание порядка в документации и коде**
**Обновлено:** 03.07.2026

---

## Назначение

Это руководство помогает поддерживать репозиторий в актуальном состоянии: документацию, структуру файлов, чек-листы обновления после спринтов.

---

## После каждого спринта

### Чек-лист обновления документации

- [ ] **README.md** — обновить прогресс (таблицу спринтов), добавить новые скриншоты если интерфейс изменился
- [ ] **PROJECT_STATUS.md** — обновить статус спринта (✅), сдвинуть прогресс, обновить метрики
- [ ] **CHANGELOG.md** — добавить записи в секцию `[Unreleased]` по формату Added/Changed/Fixed
- [ ] **ROADMAP.md** — обновить Gantt-диаграмму (done/active), обновить шилдс прогресса
- [ ] **CLAUDE.md** — добавить новые паттерны/компоненты/хуки если изменилась архитектура
- [ ] **ARCHITECTURE_HUB.md** — обновить даты, добавить новые ADR если были приняты
- [ ] **REPOSITORY_STRUCTURE.md** — отразить новые директории или изменения в src/
- [ ] **DOCUMENTATION_INDEX.md** — проверить ссылки, добавить новые документы в каталог

### Git-процесс

```bash
git checkout -b docs/sprint-XXX-update
# Внести изменения согласно чек-листу
git add -A && git commit -m "docs: post-sprint XXX updates"
git push && gh pr create --title "docs: Sprint XXX documentation update"
```

## Как добавить новый .md файл

1. Создать файл в корне или `docs/`
2. Добавить футер с навигацией (см. шаблон ниже)
3. Добавить в каталог в `DOCUMENTATION_INDEX.md`
4. Добавить ссылку в соответствующий раздел `README.md` если нужно

---

## Как добавить/обновить скриншот

1. Запустить dev-сервер: `npm run dev`
2. Сгенерировать скриншоты: `npx playwright test scripts/capture-screenshots.ts --project="Mobile Safari"`
3. Проверить размер: каждый `.webp` должен быть ≤ 500KB
4. Сохранить в `public/screenshots/`
5. Обновить `README.md` секцию «Скриншоты»

## Шаблон футера

Добавлять в конец каждого корневого .md файла:

```markdown

<sub>Обновлено: ДД.ММ.ГГГГ · [История изменений](./CHANGELOG.md)</sub>

</div>
```
