# CHANGELOG.md — версии проекта

> Формат: `## [version] - YYYY-MM-DD`
> Каждая версия содержит: **Features**, **Design Rationale**, **Notes & Caveats**

## [0.1.0] - 2026-08-01

### Features

- Реализована система статусов задач (📋🔧⚠️🐛🔒✅)
- Добавлен статус-лайн с текущим спринтом и задачей
- Создан `ACTIVE.md` для отслеживания текущей задачи

### Design Rationale

- Статусы задач упрощают визуальное отслеживание прогресса
- Статус-лайн показывает ключевую информацию в одной строке
- `ACTIVE.md` обеспечивает единую точку входа для текущей задачи

### Notes & Caveats

- Статусы задач и статус-лайн требуют ручного обновления
- `ACTIVE.md` должен обновляться вручную при смене задачи
- Система не автоматически обновляет статусы задач в `SPRINT-PROGRESS.md`
